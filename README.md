# FRCodingExercise

Android coding exercise demonstrating modern Android development with Jetpack Compose, MVVM architecture, and clean code principles.

## Architecture & Tech Stack

- **Architecture**: MVVM + Clean Architecture
- **UI**: Jetpack Compose with Material 3
- **Language**: Kotlin 2.0.21
- **DI**: Dagger Hilt 2.52
- **Networking**: Retrofit 2.11 + OkHttp 4.12
- **Async**: Kotlin Coroutines 1.9
- **Testing**: JUnit 5, MockK, Turbine, Truth
- **Min SDK**: 24 | **Target SDK**: 35

## Getting Started

```bash
git clone https://github.com/Zulqurnain/FRCodingExercise.git
cd FRCodingExercise
# Open in Android Studio Hedgehog or newer and run
```
